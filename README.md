# 台股技術行為儀表板

## 關於此頁面

這是一個純粹的台股市場資訊展示頁，由 GitHub Actions 每日自動掃描台股市場資料，並將結果呈現在網頁上。

## 功能

- 每日自動抓取台股行情（透過 FinMind / 台灣證券交易所公開資料）
- 顯示三大法人買賣超、成交量、漲跌幅等市場基本指標
- 方便快速瀏覽今日市場整體波動與資金流向

## 注意事項

- 本頁面僅用於整理與展示公開市場資訊，**不構成投資建議**
- **不包含任何交易訊號、進出場建議或獲利預測**
- **不包含任何回測績效或策略期望值**
- 請勿將頁面上的任何內容視為買賣指示，投資有風險，入市需謹慎

## 資料來源

FinMind / 台灣證券交易所公開資料，由 GitHub Actions 每日自動更新。
